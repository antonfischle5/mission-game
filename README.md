# Mission Game – Tim's Abenteuer

Ein kleines Browser-Spiel, das aus einem Python-Konsolenspiel entstanden ist. Es nutzt HTML, CSS und JavaScript und braucht keinen Server.

## Spielen

1. Öffne `index.html` im Browser.
2. Klicke auf **Spiel starten**.
3. Folge Tims Tutorial, kämpfe gegen Monster und sammle Gold.
4. Kaufe im Shop Äpfel (1 Gold), Steak (2 Gold) und Welten-Schlüssel (1.000 Gold).

Der Spielstand wird in diesem Browser automatisch mit `localStorage` gespeichert. Er wird nicht automatisch zwischen verschiedenen Geräten oder Browsern synchronisiert.

## Dateien

- `index.html` – Spieloberfläche
- `style.css` – Aussehen und Layout
- `game.js` – Spielregeln, Shop, Inventar und Speichern

## Kostenlos mit GitHub Pages veröffentlichen

1. Öffne die Repository-Einstellungen auf GitHub.
2. Gehe zu **Pages**.
3. Wähle bei **Build and deployment** die Bereitstellung über **Deploy from a branch**.
4. Wähle den Branch `main` und den Ordner `/(root)`, dann speichere.
5. Warte, bis GitHub Pages die Seite veröffentlicht hat. Die veröffentlichte URL wird dort angezeigt.

## Hinweis

Das Spiel ist ein erster Browser-Prototyp. Spielstände sind lokal im Browser gespeichert und kein gemeinsamer Online-Spielstand.
